Nov 8, 2026

1.6.0 — The opencode target, mvp

  • A new target, opencode (OpenCode 2 or later): agents to .opencode/agents/<name>.md with permissions derived from their tools, commands to .opencode/commands/<name>.md, MCP servers to .opencode/opencode.json; rules reach OpenCode through agents-md.
  • A Forge file that names opencode needs schema: 18; craftar.lock is written at schema 7 when it names it.
  • A workspace that does not name opencode sees no change.
Release v1.6.0 on GitHub →
Nov 7, 2026

1.5.0 — Five targets validated in each tool

  • cursor, copilot, agent-skills, codex and antigravity were checked by opening each tool from its CLI on a synthetic workspace; the README says what was validated, per target.
  • Generated bytes: copilot also writes .github/mcp.json for the Copilot CLI; claude-code leaves out an empty tools line in an agent.
Release v1.5.0 on GitHub →
Nov 7, 2026

1.4.0 — The gemini target removed

  • The gemini target is removed — the declared exception in the compatibility promise: the Gemini CLI no longer accepts Google login for individuals. The name is refused in targets.
  • In a workspace that used it, the files the lock recorded for it are orphans: sync removes them, and keeps a hand-edited one as orphan-drift. antigravity covers the same use.
Release v1.4.0 on GitHub →
Nov 7, 2026

1.3.1 — Documentation only

  • README and Claude Code plugin README corrections; no generated byte, lock or exit code changes.
Release v1.3.1 on GitHub →
Nov 7, 2026

1.3.0 — Hooks for codex and antigravity

  • Generated bytes: a hook ingredient with a registration is written for Codex to .codex/hooks.json and for Antigravity to .agents/hooks.json.
  • cursor and copilot run the hooks .claude/settings.json holds, so no file of theirs is written.
  • It also added a gemini target, removed in 1.4.0.
Release v1.3.0 on GitHub →
Nov 7, 2026

1.2.0 — The codex and antigravity targets

  • codex: agents to .codex/agents/<name>.toml; rules through agents-md, commands and skills through agent-skills.
  • antigravity: rules to .agents/rules/, agents to .agents/agents/, MCP servers to .agents/mcp_config.json.
  • A Forge file that names either needs schema: 16; a workspace that names neither sees no change.
Release v1.2.0 on GitHub →
Nov 6, 2026

1.1.0 — The cursor, copilot and agent-skills targets

  • cursor (.cursor/rules/, .cursor/agents/, .cursor/mcp.json), copilot (.github/instructions/, .github/copilot-instructions.md, .github/agents/, .github/prompts/, .vscode/mcp.json) and agent-skills (.agents/skills/).
  • What a tool already reads in another target's file is not written twice.
  • A Forge file that names one needs schema: 15; a workspace that names none sees no change.
Release v1.1.0 on GitHub →
Nov 6, 2026

1.0.0 — The compatibility promise

  • Nothing changes in what craftar writes. From here on, breaking a command, a flag, an exit code, a --json shape, the loading of a Forge schema or the reading of the lock needs a major version, and a change to generated bytes comes in a minor.
Release v1.0.0 on GitHub →

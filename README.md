# Craftar — site

Landing page for Craftar, a build system for AI-coding harnesses.

Static site, no build and no dependencies: the home page `index.html`, the capabilities documentation `docs/index.html`, the stylesheet both share `site.css`, and `llms.txt`, the plain-text twin of both pages. `og.html` is the source of `og.png` (rendered at 1200×630, `noindex`).

Published by GitHub Pages from the `main` branch (root).
